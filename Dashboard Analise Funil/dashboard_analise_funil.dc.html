Win Rate Data de Criação do Orçamento info Como funciona
  • Filtra pela data de criação do orçamento.
  • Win rate = valor faturado ÷ valor enviado ao cliente. O enviado inclui tudo o que foi para o cliente: faturado, não aprovado (inclusive cancelados) e aprovado ainda não faturado (análise de crédito, bloqueio de pagamento, separação etc.). Esses aprovados só passam a contar no faturado quando faturarem.
  • Recotações da mesma negociação (mesmo cliente e itens, até 15 dias de diferença) não duplicam, conta só a versão mais recente, a menos que uma delas já tenha faturado.
  • Comparação justa com o período anterior: o período anterior só conta como faturado o que faturou até a data equivalente, com o mesmo número de dias úteis. Assim os dois períodos tiveram o mesmo tempo para faturar.
